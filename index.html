Aqui iran los detalles de los comandos

Git

  • git init: Inicializa un nuevo repositorio Git en el directorio actual.
  • git clone [url]: Clona un repositorio remoto en tu máquina local.
  • git add [archivo]: Agrega un archivo específico al área de preparación (staging area).
  • git commit -m "mensaje": Crea un commit con los cambios agregados al área de preparación.
  • git push: Envía los commits locales a un repositorio remoto.
  • git pull: Obtiene y fusiona los cambios del repositorio remoto en tu rama actual.
  • git status: Muestra el estado de los archivos en el directorio de trabajo y el área de preparación.
  • git log: Muestra el historial de commits del repositorio.

Docker

  • docker build -t nombre_imagen .: Construye una imagen de Docker a partir del Dockerfile en el directorio actual.
  • docker run -d -p puerto_local:puerto_contenedor nombre_imagen: Ejecuta un contenedor en segundo plano y mapea los puertos.
  • docker ps: Muestra los contenedores en ejecución.
  • docker stop id_contenedor: Detiene un contenedor en ejecución.
  • docker rm id_contenedor: Elimina un contenedor detenido.
  • docker images: Muestra las imágenes de Docker disponibles en tu máquina.
  • docker rmi nombre_imagen: Elimina una imagen de Docker.

Ngrok

  • ngrok http puerto_local: Crea un túnel seguro a tu servidor local en el puerto especificado.
  • ngrok authtoken token: Configura tu token de autenticación para usar Ngrok con tu cuenta.
  • ngrok status: Muestra el estado actual de los túneles activos.
  • ngrok kill: Detiene todos los túneles activos.
